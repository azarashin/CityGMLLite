# CityModel Runtime package

This UPM package is the Unity runtime boundary for CityGMLLite datasets.

The package skeleton intentionally contains no dataset-loading behavior yet. Follow
the MVP roadmap in GitHub issue #23; the first runtime implementation begins with
the data contracts in issue #1 and the loader in issue #12.

## Local installation

In Unity Package Manager, choose **Add package from disk** and select this
directory's `package.json` file.
